# Mohamed Ahmed — Portfolio

Static personal portfolio built with [Astro](https://astro.build). Two interchangeable
themes, all content managed from code, no backend, deployable on Vercel's free plan.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
```

- Switch theme: `src/config/site.js` → `theme`
- Edit your info: `src/data/profile.js`
- Add a project: images in `public/projects/<slug>/` + an entry in `src/data/projects.js`

**Full instructions: [PORTFOLIO_GUIDE.md](PORTFOLIO_GUIDE.md)**
